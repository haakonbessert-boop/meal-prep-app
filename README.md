# Meal Prep

Kleine Web-App (PWA) für den Reis-Plan: 2 Mahlzeiten am Tag, Einkauf und Kochen Mo und Do, Tage gegen das Ziel, Einkaufslisten mit Kosten zum Abhaken, Prep-Schritte.

- `data/` Rezepte und Zutaten (Quelle: Reis-Plan Beispielwoche im Second Brain)
- `src/` Oberfläche, Service Worker, Icons
- `python3 build.py` baut `docs/` (wird von GitHub Pages ausgeliefert)
