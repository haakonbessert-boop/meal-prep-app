# Meal Prep

Kleine Web-App (PWA) für das wöchentliche Meal Prep: Rotationswoche wählen, Portionen und Makros sehen, Einkaufsliste abhaken, Prep-Schritte für Montagabend.

- `data/` Rezepte und Zutaten (Quelle: 4-Wochen-Ernährungsplan)
- `src/` Oberfläche, Service Worker, Icons
- `python3 build.py` baut `docs/` (wird von GitHub Pages ausgeliefert)
